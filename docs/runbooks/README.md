# runbooks

O runbook diz como fazer: condição, passos e verificação.

Playbook e SOP não são outra pasta. Um playbook é uma seção dentro do runbook.

Nome: `runbook-nnn-titulo.md`. `nnn` tem três dígitos e começa em `001`. A ordem é a `date`, crescente. No mesmo dia, o título. Entrar, sair ou mudar a data recalcula a sequência desde `001` e atualiza os links.

Frontmatter na primeira linha: `status` (`active` ou `retired`) e `date` (`YYYY-MM-DD`). Sem `type`, `id`, `version`, `tags`, `related_docs` ou `review_date`. A cadência, quando o procedimento tem uma, fica no corpo.

Não há runbook neste repo.
