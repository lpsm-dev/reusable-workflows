# _assets

Imagem usada por mais de um documento deste `docs/` fica aqui.

## 1. O que entra

PNG e SVG compartilhados. A pasta não tem contrato próprio. Mermaid continua no documento.

## 2. Como ligar

A partir de `docs/`, o link é `_assets/<arquivo>`. A partir de `docs/adrs/`, o link é `../_assets/<arquivo>`. A partir de `docs/handbooks/gitleaks/`, o link é `../../_assets/<arquivo>`.

Imagem usada por um documento só fica em `_assets/` ao lado desse arquivo. O link, nesse caso, é `_assets/<arquivo>`.
